# SuperTask 1.0 界面原型 · 八套方案对比（2026-08-25）

纯 HTML 单文件原型，位于 `docs/prototypes/`，浏览器直接打开预览。入口：`docs/prototypes/index.html`。

> 第一批 A/B/C（浅色中性）用户反馈不够惊艳，追加第二批 D/E（冲击型），共同约束全部落地；D 已按反馈改回浅色并重排信息层级；第三批 F 为浅色极客时尚风；第四批 G 经对话定调后产出，初稿赤陶暖色被否，改清新薄荷；**第五批 H 为用户亲自收敛的方向：Linear 风格 + 左侧栏 + 卡片清单/详情 + 全量功能注册表**——大概率是最终定稿基础。H 已按四点反馈二次修正（柔和无直角 / 查证的 Linear 官方 token / 等高卡片 / 详情重排），并用浏览器截图 + DOM 实测验收。

## 共同约束（八套均落地）

- 核心功能占位齐全：服务启停（spring-boot:run / npm run）、状态与端口、健康检查（改端口自动跟随）、分服务日志、工具链探测（JDK/Maven/Node，只探测不代装）、Job Object 进程树停止说明
- 1.x 占位导航：模板 / 环境 / Git / 容器 / 网关 / 云 / AI 可见但禁用，带版本标签
- 缩放适配：根字号 `clamp()` 流式缩放；每套 2 个断点
- SVG 图标（无 emoji）、可键盘聚焦、150-300ms 过渡
- A/B/C：浅色中性基调（slate / stone / zinc）；D/E：深色，均支持 `prefers-reduced-motion` 降级

## 第四批 · 对话定调方向（2026-08-25 17:47–17:57，四问定位后产出）

对话结论（AskUserQuestion 四问）：参照 **Vercel/Linear**；不满 = 太像模板没个性 / 视觉不够惊艳 / 信息层级仍不对；色彩直觉初选暖奶油+赤陶（**后被否，改清新**）；排版性格 = 手作友好感（大圆角、粗字重、图形化点缀）。

| 维度 | G · 清晨薄荷 MORNING MINT |
|---|---|
| 文件 | `prototype-g-morning-mint.html` |
| 风格 | Linear/Vercel 的克制骨架 × 清新薄荷（#10A37F 唯一强调色）× 空气感白底（#FAFCFB 带绿调）× 实体按键触感 |
| 层级策略（针对"信息层级不对"） | 全页只有一个绿：启动全部大胶囊主按钮（3px 深色底边 + 按压位移，实体键感）；服务行是唯一大块内容；工作区统计/工具链全部降为安静细条 |
| 手作签名（针对"没个性/不惊艳"） | 顶部 4px 晨光渐变条（全页唯一渐变）、章节标题薄荷虚线短划、指向主按钮的手绘虚线箭头批注（"按依赖顺序一键起飞"）、状态点呼吸光环 |
| 排版 | 系统 sans 粗字重（800）大名称 + JetBrains Mono 数据；kind 标签用前导圆点（绿=Spring / 天蓝=Node）保持单色纪律 |
| 服务呈现 | 行式（呼吸状态点 + kind 点标 + L1/L2 层级 + $ 命令 + mono 指标 + 胶囊按钮），异常行内展开浅红原因条与下一步 |
| 检查器 | sticky 右栏：kv + yaml 片段（雾绿底）+ 墨绿底薄荷字"清晨终端" + 重启/停止进程树 |
| 风险 | 薄荷绿与"运行中"状态色同族，语义耦合需在实现时留意；系统 sans 粗字重的中文渲染（雅黑 800 缺失时回退 700） |
| 断点 | ≤1200px 检查器下沉；≤800px 导航收字、行内动作铺满、批注隐藏 |
