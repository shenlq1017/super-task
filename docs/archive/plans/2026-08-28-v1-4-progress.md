## 已落地

### 地基
- 错误码：`PLATFORM_UNSUPPORTED` / `BUILD_TOOL_AMBIGUOUS` / `GRADLE_WRAPPER_MISSING` / `TASKFILE_NOT_FOUND` / `TASKFILE_INVALID`（error.rs，序列化口径对齐既有测试）。
- app data v3：新增 `locale`（默认 `auto`），v2→v3 迁移保留未知键（appdata.rs，版本断言已同步 3）。
- `app.savePrefs` 入参扩展 `locale`（src-tauri/commands.rs）。
- Cargo：`nix`/`libc`（cfg unix）、`procfs`（cfg linux）；`netstat2` 挪入 cfg(windows)——其 linux 分支与新版 libc 源码不兼容，会阻塞 Linux 构建（Linux 监听表改走 /proc 自实现）。

### Phase 1：proc 平台层
- `src/proc/mod.rs`：`ProcessTree` trait（spawn/terminate/pids/has_live_process/total_cpu_ms/working_set_bytes）+ `create_tree()` 工厂。
- `src/proc/windows.rs`：原 `job.rs` 整体迁入（Job Object，行为/错误码不变），实现 trait。
- `src/proc/unix.rs`：独立进程组 `setpgid(0,0)`；停止 = killpg SIGTERM → 5s 宽限 → SIGKILL；Linux `PDEATHSIG(SIGKILL)`；Drop 兜底 SIGKILL；pids：Linux procfs 按 pgrp 扫描、macOS `ps -axo pid=,pgid=`；指标：Linux procfs utime+stime/rss，macOS `ps cputime/rss`，失败降级 None。
- engine.rs：`Slot/ScriptSlot/DetachedSlot` 持 `Arc<dyn ProcessTree>`，spawn/terminate 全部走 trait；`job.rs` 删除。
- 验证：`cargo test -p supertask-core` 239 单测全绿（Windows）；`cargo check --target x86_64-unknown-linux-gnu / aarch64-apple-darwin` 通过。

### Phase 2（部分）
- ports.rs：`tcp_listeners()` 平台分派；Linux 解析 `/proc/net/tcp{,6}`（LE hex → 规范地址）+ procfs fd→pid（inode→socket）；macOS `lsof -nP -iTCP -sTCP:LISTEN`；通配符归一化 0.0.0.0；`process_name_of` Linux /proc/comm、macOS ps。失败 → `PORT_SCAN_FAILED` 口径不变。
- discover.rs：Unix imp 完整实现（监听端点复用 ports 表 + 地址回解；进程名 /proc|ps；cwd/cmdline /proc|lsof；CPU% 差分采样 / ps %cpu；内存 rss）；`taskkill_tree` Unix 侧 SIGTERM→5s→SIGKILL；kill 护栏平台化（Windows ≤4 不变，Unix init=1），三平台统一「须有 LISTEN 端口」。
- Linux/macOS target `cargo check` 通过。

### Phase 2（剩余，已完成）
- engine 脚本 shell（§4.2）：Windows `cmd.exe /C` 不变；Unix `bash -c`，PATH 无 bash 回落 `sh -c` 并在脚本日志头警告一次。测试桩 `spawn_fail` 同步平台化（unix `sh -c exit 1`）。
- probe 平台已知位置（§4.3）：`resolve_program` PATH 未命中后补 macOS（homebrew、/usr/local/bin、sdkman、nvm）与 Linux（mise shims、/usr/lib/jvm/*/bin）候选，只读不改 PATH；Windows 不变。
- 更新分平台（§4.5）：`app.update.install` Linux 同步返回 `PLATFORM_UNSUPPORTED`（手动替换 AppImage 指引），Windows 走原路径；`app.update.check` 三平台可用。
- docs/spec/ipc.md：`app.savePrefs`/prefs 补 `locale`、错误码表补 1.4 五码、更新节补 Linux 行为。

### Phase 3：Gradle（subagent 实现，已验收）
- spec：`build_tool: maven|gradle`（非法 `SPEC_INVALID`）；探测并存 → `BUILD_TOOL_AMBIGUOUS`、缺失 → `MISSING_TOOL`。

- 打包（dmg 签名公证/AppImage）、三平台 CI matrix、Playwright 四语用例：真机/CI 依赖，本机不可完成。
