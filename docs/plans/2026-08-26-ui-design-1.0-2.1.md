## 0. 设计常量（与设计令牌一致）

```
底色 bg #F7F8F8 · 卡片 surface #FFFFFF · 灰 surface-2 #F3F4F5 · 描边 line #E6E6E6
主文 t1 #222326 · 次文 t2 #62666D · 三文 t3 #8A8F98 · 品牌 accent #5E6AD2
状态：running #27A644 · unhealthy #EAB308(dot)/#9A6700(text) · stopped #8A8F98 · exited #DC2626
字体：Inter Variable（UI） + 等宽（路径/端口/日志/版本号）
圆角：xs 5 · sm 8 · md 12 · lg 16 · pill 9999（无直角）
客户端结构高度：chrome 36 · topbar 50 · sidebar 展开 14.5rem/收起 3.25rem · statusbar 30
动效：180–220ms cubic-bezier(.22,1,.36,1)；hover 150–200ms；尊重 prefers-reduced-motion
```

**图标纪律（来自 ui-ux-pro-max 验收清单）**：全部 SVG（Lucide/Heroicons 线性风，1.8 描边），**禁止 emoji**；可点击元素 `cursor:pointer`；hover 有 150–300ms 过渡；键盘 `:focus-visible` 可见；`prefers-reduced-motion` 全部降级；桌面优先、不出现横向滚动。

```
│ 模板  /templates   (soon 1.1)                                          │
│ 环境  /env          (live 探测 / soon 1.2 安装)                        │
│ Git   /git          (soon 1.1)                                         │
│ 容器  /docker       (soon 1.3)                                         │
│ 网关  /gateway      (soon 1.6)                                         │
│ 云    /cloud        (soon 2.0)                                         │
│ AI    /ai           (soon 2.1)                                         │
│ 设置  /settings     (live)                                             │
├────────────┴────────────────────────────────────────────────────────┤
│ statusbar 30px：工具链探针 ─── 同步状态 ─── 计数/快捷键/版本           │
└──────────────────────────────────────────────────────────────────────┘
```

- **11 个入口 1.0 全部画出**，不可用项：灰显 + 「即将 x.x」徽标 + hover 浮出版本说明（不隐藏，避免以后挤布局）。
- 导航、命令面板、路由**全部读功能注册表 `features`**，壳上禁止写 if。
- 侧栏可收起为纯图标态（3.25rem），收起时文字/徽标/路径隐藏，hover 出 tooltip。

### 1.2 路由表（1.0 就全部注册）

| 路径 | 1.0 内容 | 以后 | 进入方式 |
|------|----------|------|----------|
| `#/welcome` | 添加工作区 / 最近列表 | → 自动进最后工作区 | 首次 / 无最近 |

| `#/templates` | ComingSoon（仅标题版本） | 1.1 模板 | 侧栏「模板」 |
| `#/env` | **live** ProbeBar + ComingSoon 安装区 | 1.2 安装升级 | 侧栏「环境」 |
| `#/git` | ComingSoon | 1.1 | 侧栏「Git」 |
| `#/docker` | ComingSoon | 1.3 | 侧栏「容器」 |

### 1.3 跳转 / 前后逻辑（每个跳转都明确）

1. **启动 App**：有「最后打开」且路径仍在 → 直进 `#/run`（该工作区）；否则 `#/welcome`。
2. **welcome → run**：点「添加工作区」（系统文件夹对话框→选已存在目录）→ 若无 yaml 触发**扫描向导** → 确认写入 → 进 `#/run`；点最近列表项 → `#/run`。
3. **run → 抽屉**：点服务卡片 → 右侧抽屉展开该服务；再点空白/关闭 → 收起。抽屉 Tab 互相切换（日志/环境/健康/终端/指标/容器/代理），前四个 live，后四个占位禁用。
4. **run ⇄ logs**：run 卡片「查看日志」→ `#/logs` 并预选该服务；logs 左列表点服务 → 右视图切换。
5. **run/config → 配置**：run 卡片「配置」或侧栏「配置」→ `#/config`；配置页「表单↔原文」Tab 切换，脏切换弹确认框。
6. **侧栏占位 → 自身**：模板/Git/容器/网关/云/AI 点击只进 ComingSoon 本页，不报错、不假数据。
7. **命令面板（⌘K / Ctrl+K）**：覆盖层；索引全部 features（含 soon）。live 项回车→跳转；soon 项回车→ toast「将在 x.x 提供」；支持模糊过滤、↑↓ 选择、Esc 关闭。
8. **浏览器后退/前进**：hash 路由，原生 back/forward 生效，`popstate` 重新渲染；抽屉/面板状态不进历史（仅顶层路由进历史）。
9. **设置 → 外观**：切换 亮/暗跟随系统；1.0 仅 light 实装，dark 占位（路线 2.x 才做，但开关可见）。

## 2. 各页面设计

### 2.1 欢迎页 `#/welcome`
- 居中卡片：产品名 + 一句话（本机多服务可视化工作台）。
- 主操作：**添加工作区**（大按钮，触发系统目录选择）。
- 次级：最近列表（路径 + 上次打开时间 + 移除「⋯」）。无最近时显示空态引导，不空白无按钮。
- 右下角：导入说明（从 pom / package.json 生成）。

### 2.2 运行页 `#/run`
- **pagehead**：工作区名 + 全局操作（启动全部 / 停止全部 / 打开目录 / ⌘K）。
- **卡片网格**（每张 = 一个 service）：
  - 左侧状态点（颜色随 state）+ kind 图标（spring-boot / node / script）。
  - 标题 id；副行 kind · port · 运行栈（Spring Boot 3.2 / Node 20）。
  - 一行概览 chip：PID、运行时长、最后健康。
  - 悬浮：卡片轻微上浮 + 描边高亮 + 右侧浮现「起/停/重启/日志/配置」快捷操作。
  - 底部按钮：启动 / 停止 / 重启（按 state 显示可用态，禁用态灰）。
  - 点击卡片非按钮区 → 打开右侧抽屉。
- **空工作区（0 服务）**：引导卡「去配置页扫描生成草稿」。
- **右侧抽屉**（选中服务）：见 2.2.1。
- **详情头元信息条**（服务标题下方）：命令行卡片用深色终端风（`$` 提示 + 等宽正文 + 复制按钮）；元信息条字段标签用**常规中文小字**（灰色，与值同档或仅小半档，**禁止微型大写英文式标签**——中文场景下 uppercase 无意义，小一号大写会显得费眼且失衡）；值为主要信息（等宽字体，端口紫色、运行时长绿色等语义色仅用于强调）。
- **扫描向导**（modal，首次无 yaml 或「重新扫描」）：列出探测到的 spring 模块 + node 包（含依赖/端口/警告），可勾选/编辑，确认写入 `supertask.yaml`。

#### 2.2.1 服务抽屉 Tab
| Tab | 内容 | 状态 |
|-----|------|------|
| 日志 | 跟随底部/暂停/清屏；等宽日志视图 | live |
| 环境 | port 数字输入 + env 键值表 + 保存（写 yaml，黄条「未重启」） | live |
| 健康 | 类型、最近结果、最近时间、失败原因、探测明细 | live |
| 终端 | ComingSoon（1.5 PTY） | 占位禁用 |
| 指标 | ComingSoon（1.2 CPU/内存） | 占位禁用 |
| 容器 | ComingSoon（1.3） | 占位禁用 |
| 代理 | ComingSoon（1.6） | 占位禁用 |

### 2.3 日志页 `#/logs`
- 左：服务列表（含正在跑的 script），选中高亮，状态点。
- 右：与抽屉「日志」同款视图（跟随/暂停/清屏），顶部显示服务名 + 状态。
- 无搜索（占位提示 1.2）。

### 2.4 配置页 `#/config`
- **Tab 表单**：工作区 name、全局 env 表、服务列表增删（id/kind/module|dir/port/grace）、`depends_on` 多选。
- **Tab 原文**：`<textarea>` 原样 YAML；保存原样写盘并解析，失败标行号。
- 切换脏确认；表单保存丢注释 → 保存前 toast 一次说明。
- 「重新扫描并合并」：**1.0 仅当尚无服务时**显示扫描按钮（不自动 merge）。

### 2.5 占位页（统一 `ComingSoon`）
- 大图标 + 功能名 + 版本徽标「即将 x.x」+ 一句话价值。
- **禁止假列表/假数据**。
- `/env` 例外：顶上复用 **ProbeBar**（live 探测 JDK/Maven/Node/包管理器），下方 ComingSoon 安装区（1.2）。

### 2.6 设置页 `#/settings`
- 分组标题（1.0 画出）：常规（真：打开最后工作区开关）/ 外观（真：亮/暗跟随系统）/ 工具链（占位 1.2）/ 网络代理（占位 1.2）/ 更新（占位 1.1，含当前版本号）/ 账号（占位 2.0）/ 关于（版本、许可）。
- 占位分组显示「即将 x.x」副标题，不展开假控件。

## 3. 交互与动效细则（顶级 UI 体验）

### 3.1 状态机可视化（核心）
服务状态：`stopped → starting → running ↔ unhealthy → stopping → stopped`，外加 `exited`。
- `starting`：状态点呼吸动画（渐变），按钮显示「取消」；grace 内不标 unhealthy。
- `running`：绿色实点 + 轻微 pulse（表示活着）。
- `unhealthy`：黄色点 + 黄条「进程在但健康检查失败」。
- `stopping`：点灰转圈。
- `exited`：红点 + 「启动」可用。
- 任何变更走 180ms 过渡，数字/时长 `tabular-nums` 等宽不跳动。

### 3.2 悬浮（hover）
- 卡片：translateY(-1px) + 描边 accent 30% + 阴影 shadow-2（180ms）。
- 按钮：底色加深 / 描边高亮，图标与文字 `vertical-align:-.125em` 严格居中。
- 侧栏项：左缘 2px accent 指示 + 背景 surface-2。
- 占位入口：hover 浮出「将在 x.x 提供」版本药丸。
- 全部 hover 有 150–200ms 过渡，无瞬变。

### 3.3 命令面板
- 唤起：⌘K / Ctrl+K（全局），或 pagehead 搜索框聚焦。
- 覆盖层 + 毛玻璃 backdrop；输入框 + 过滤结果列表（分组：导航 / 操作 / 即将）。
- ↑↓ 移动、Enter 执行、Esc 关闭；结果项 hover 高亮。
- 选中 live → 路由跳转；soon → toast「将在 x.x 提供」。

### 3.4 反馈
- **Toast**：右上角堆叠，自动消失（成功绿 / 警告黄 / 错误红），含操作（如「查看日志」）。
- **确认框**：脏切换、移除工作区、停止全部（有运行中时）。
- **加载**：启动全部时 pagehead 按钮 spinner + 卡片 state 流式更新。
- **错误说人话**：缺工具链「未找到 mvn。请安装并确保在 PATH。1.2 支持一键安装」；端口冲突、依赖成环、yaml 解析失败均给出可执行指引，不「假成功」。

### 3.5 可达性
- 所有可点击元素 `:focus-visible` 描边 accent。
- 图标按钮带 `aria-label`；抽屉/面板用 `role=dialog`/`aria-expanded`。
- 键盘：⌘K 面板、Esc 关层、↑↓ 选择、Enter 确认、Tab 顺序合理。
- 对比度：t2/t3 在 bg 上 ≥ 4.5:1；状态色用「色 + 文字/描边」双通道，不只靠颜色。

## 4. 版本分阶段（1.0 → 2.1，界面层面）

| 版本 | 界面新增 | 本原型呈现 |
|------|----------|-----------|
| 1.0 | 完整壳 + run/logs/config/settings/env(探测)/命令面板 | 全部 live |
| 1.1 | 模板库、Git 克隆/状态、开 IDE、托盘/更新 | 占位页可见，hover 出版本 |
| 1.2 | 工具链安装升级、端口占用一键改、密钥、日志搜索/导出、CPU/内存、profile/分组 | 占位 + ComingSoon |
| 1.3 | 容器 compose、镜像、Redis/MySQL sidecar | 占位 |
| 1.4 | macOS/Linux、Gradle、i18n | 占位 |
| 1.5 | 导出包、CLI、MCP | 占位 |
| 1.6 | 网关 nginx/apache 模板、Caddy HTTPS | 占位 |
| 2.0 | 云账号、同步、一键迁移 | 占位（账号按钮未登录态） |
| 2.1 | AI 解释日志/改端口、README 导入生成 YAML | 占位（AI 入口） |

原则：**占位永远可见、版本明确、绝不假数据**；新功能 = 新 route 填 ComingSoon，壳不变。
