### Phase 1 — 路由模型与静态校验 ✅
- 错误码五枚：`GATEWAY_NOT_CONFIGURED` / `GATEWAY_ROUTE_INVALID` / `GATEWAY_BINARY_MISSING` / `GATEWAY_CONFIG_INVALID` / `GATEWAY_START_FAILED`（`error.rs`，序列化快照测试）。

- 静态校验（`gateway/mod.rs::validate_static` + `ensure_static`）：kind 枚举、port 1024–65535、网关端口不撞服务端口、(host,path) 去重、path/host 语法（含 `*.localhost`）、target/upstream 恰一、target 存在且有 port、upstream 语法（拒绝 scheme/userinfo/路径）。打开时 warning（open warnings）、apply/start 硬错误。

### Phase 2 — render 三家 ✅（纯函数，零新依赖）

### Phase 4 — 引擎托管 GatewaySlot ✅
- `Inner.gateway: Option<GatewaySlot>`（未配置零开销）；快照新增独立 `gateway` 字段（`GatewayRuntimeView`），不进 services 列表。
- `gateway_start` = 静态校验 → 探测 → render 落盘 → spawn 校验 → spawn（Job 进程树）→ Starting；TCP 健康（loopback 双栈，grace 3s）达标转 Running；日志泵 source=`gateway`（`LogSourceKind::Gateway` 新枚举，文件 `.supertask/logs/gateway.log`）；退出收尾与 `spawn_waiter` 同语义（crash → exited + `GATEWAY_START_FAILED`）。
- `gateway_stop`（进程树终止、幂等）/ `gateway_restart`；`gateway_apply` = 静态校验（fail-fast）→ **save_form 先落盘**（`YAML_CONFLICT` 时网关保持运行不受影响）→ 重建 slot → 运行中 stop→start（非热重载），返回 `restarted`。
- `stop_all` / `close` / `detach` / CLI `down` / 引擎退出清场一律含网关；detach 网关不进 DETACHED 移交（随工作区会话终止）。
- `ports_inspect`：网关进程树计入托管集合与自身排除（1.2 语义成立）。
- `start_all`（桌面「全部启动」）先服务后网关；网关失败不阻塞主目标（错误落 slot.last_error + 网关日志）。
- 引擎测试（Windows 桩）：TCP 监听桩（cmd 包装 PowerShell listener）全生命周期（start→running→重复启动 `ALREADY_IN_PROGRESS`→stop 端口释放→stop_all 清场）、错误映射三分支（校验失败/显式 bin 缺失/enabled=false）、preview 纯内存断言、apply 冲突与重启。

## 剩余（真机验收期）

- 规格 §14.4 真机矩阵：nginx 反代真实 Spring+Node 工作区、caddy `https://localhost` 无警告 + trust/untrust、apache（XAMPP/brew/apt）最小反代、三引擎启停无残留、CLI `up --wait healthy -- cmd` 含网关、1.0–1.5 回归抽样（Windows 全量）。
- Playwright 网关页一条中文用例（草稿→应用→状态）；浏览器 mock 点选冒烟（空态→草稿→diff→应用→校验→启停）。
- 已知实现期决策（与规格的差异备案）：
  1. `gateway.apply` 采用「先 save_form 落盘、后重启」顺序——`YAML_CONFLICT` 时网关保持运行不受影响（对齐 1.2 ports_assign 的部分失败口径并更优）。
  2. detach（切工作区）时网关终止、不进 DETACHED 移交（规格 §2.4「网关随引擎退出终止」的自然推论；服务保持运行语义不变）。
  3. `gateway.status` 的 caddy 信任状态不返回 `trusted` 布尔（无法静默探测系统信任库）；页面常显「信任本机 CA」入口 + 风险确认。
  4. CLI 不提供 `gateway` 子命令与 trust（规格红线）；MCP 工具集不变（7 个）。
  5. apache 模块目录按 bin 同级 `modules/` 推断（XAMPP 与官方 zip 布局一致），非探测；校验失败原文透出。
