# 1.0 UI 扩展占位

1.0 功能少，但窗口结构按 2.0 来。后期加模板/容器/云/AI 是填槽，不是改壳。

左侧 **11 个入口 1.0 就画全**。不可用项：灰 + 「即将」+ hover 写版本。不要隐藏，隐藏等于以后挤布局。

标题栏「账号」：未登录样式，点击说明 2.0。不要做假登录。

## 功能注册表

单一模块（概念名 `features.ts`），导航、命令面板、路由都读它。

```ts
type FeatureStatus = "live" | "soon";

type Feature = {
  id: string;
  path: string;
  navLabel: string;
  status: FeatureStatus;
  since: string; // "1.0" | "1.1" | ...
};
```

加功能：改注册表 + 填页面。禁止在 AppShell 里写一长串 if。

命令面板 1.0 只索引 `status === "live"`。`soon` 可搜到但提示版本（可选，免得以为坏了）。

## YAML 预留

- 未知字段 **保留并写回**（不要 round-trip 丢 `gateway:`）  
- 允许顶层占位键：`templates` / `toolchain` / `git` / `docker` / `gateway` / `cloud` / `ai`，1.0 读到就忽略  
- 不要 `deny_unknown_fields`  

这样 1.1 的 yaml 在 1.0 里仍能打开，只是多出来的段不生效。

## 设置页分组（1.0 画出标题）

- 常规（真）：工作区根目录、打开目录的程序  
- 外观（真）：亮/暗跟随系统  
- 工具链（占位说明 1.2）  
- 网络代理（占位 1.2）  
- 更新（占位 1.1，可先放「当前版本」）  
- 账号（占位 2.0）  
- 关于  

## 明确不要

- 1.0 做可拖拽自定义导航（过度）  
- 1.0 做插件 API（2.2）  
- 为占位页写假数据演示  
- 隐藏「即将」入口「等做了再加菜单」
