SuperTask · v1.0 UI Prototypes

八套界面原型方案对比

同一份功能（supertask.yaml 驱动的 Spring Boot 多模块 + Node 服务启停、分服务日志、工具链探测、1.x 占位导航），不同的视觉风格与布局结构。A/B/C 第一批浅色中性；D/E 第二批冲击型（D 已改浅色）；F 第三批极客「墨格终端」；G 对话定调「清晨薄荷」；H 为用户收敛版：Linear 风格 + 左侧栏（可收起）+ 卡片清单/详情 + 全量功能注册表（含纯 CSS 可交互：侧栏收展、详情 Tab 切换、日志全屏）。全部为纯 HTML 单文件、响应式缩放适配，可直接在浏览器中打开预览。

方案 A · 经典工作台

左侧导航 + 服务表格 + 底部日志抽屉 + 状态栏
  • IDE 风格（VSCode / JetBrains），开发者最熟悉的心智模型
  • 表格密度高，适合服务数量多（10+）的场景
  • 日志抽屉 Tab 常驻底部，状态栏承载工具链 / CPU / yaml 同步状态
  • ≤1152px 侧栏收成图标栏；≤832px 侧栏转顶部横条

方案 B · 卡片仪表盘

顶部标签导航 + 统计行 + 服务卡片网格 + 右侧详情抽屉
  • 现代 SaaS 风格，视觉最友好，状态一眼可辨（大状态环）
  • 卡片网格 auto-fill 自适应列数，天然适配任意宽度
  • 详情抽屉内嵌 yaml 片段 + 迷你日志，信息聚合在选中服务上
  • 占位功能以带锁 Tab 呈现；≤768px 顶栏精简为图标

方案 C · 三栏命令中心

图标轨道 + 服务列表 + 工作区（指标 / YAML / 终端）
  • Linear / Raycast 风格，键盘流、等宽字体、信息密度最高

  • 列表按服务类型分组（Spring / Node），选中即切换右侧工作区
  • ≤1216px 工作区堆叠；≤896px 列表转顶部横向卡片条

方案 D · Aurora 领航台（浅色）★

浅色柔彩极光 + 玻璃白 + 服务跑道列表为主角 + 悬浮日志台
  • 围绕核心循环组织：打开工作区 → 一键启动 → 盯日志 → 出错说人话 → 停干净
  • 服务列表是绝对主角：行内启停/重启、拓扑层级 L1/L2 与依赖标注、迷你 sparkline

  • 依赖顺序显性化（启动按层串行、停止逆序）；≤1200px 隐藏次要指标；≤800px 动作整行铺开

方案 E · 星图依赖引擎 ★

  • ≤1240px 检查器转浮层；≤900px 探测条仅留警告项、控制台折叠收起

方案 F · 墨格终端 INKGRID ★

纸白点阵网格 + 墨黑硬边框硬投影 + 酸性绿唯一强调色 + 等宽主导排版
  • 浅色极客时尚：瑞士网格 × 新粗野主义 × 终端排版（JetBrains Mono 主导，命令行 $ 前缀、编号导航、// 注释微文案）

方案 G · 清晨薄荷 MORNING MINT ★

薄荷绿唯一强调 × 空气感白底 × 实体按键触感 × 单一大主按钮层级

方案 H · Linear 工作台 ★（收敛版）

左侧栏（收起图标/展开图文）+ 等高卡片清单 + 圆角大卡详情（事实条 + 分段 Tab）· Linear 官方浅色 token
  • 按查证的 Linear 官方规范重做：品牌紫 #5E6AD2、页面底 #F7F8F8、Inter 字距收紧、180ms 缓动 + 按压 scale(.97)
  • 全局柔和无直角：药丸按钮/徽章 9999px、小件 10px、卡片 14px、详情大卡 18px
  • 卡片强制等高（三行结构：标题/状态/底注）：异常服务的警告收成单行截断，拓扑层级 L1–L3 作底注标签，实测 91px 全一致
  • 详情重排：九宫格改为一排事实药丸（命令/端口/健康/拓扑/PID…）+ 分段控件 Tab，全部装进一张圆角大卡
  • 纯 CSS 可交互：侧栏收展、Tab 切换、日志全屏都能点；≤1200px 清单转顶部网格；≤800px 侧栏强制收起
