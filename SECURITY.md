# Security Policy

## Supported versions

Security fixes are made against the latest `main` branch and the latest
published release.

## Reporting a vulnerability

Please use GitHub Security Advisories for this repository. Do not disclose
credentials, tokens, private keys, or a working exploit in a public issue.

Include the affected version, operating system, reproduction steps, impact,
and any suggested mitigation. Please allow time for triage before public
disclosure.

The cloud server is an experimental self-hosted reference implementation. Do
not expose it to the public Internet without adding production TLS,
authentication controls, logging policy, backups, and secret rotation.
